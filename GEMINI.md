# Legal-marketing data (Probative Growth)

Use the `probative` MCP server (https://probativegrowth.com/mcp, read-only, no key).

1. Call `list_datasets` when unsure which dataset answers the question.
2. For a state's lawyer advertising rules, call `get_state_rules` with the two-letter state code.
3. Quote the source, version and DOI that come back with every answer, and say it is not legal advice.
