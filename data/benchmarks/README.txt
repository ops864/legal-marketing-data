Not legal advice. Probative benchmarks, 2025–2026 are approximate bands, tiers and rounded values from Probative's own data, kept for marketing planning. They are not a forecast for any one firm.
Probative is a marketing firm, not a law firm; not legal advice.

Human page: https://probativegrowth.com/research/benchmarks/

Columns:
  id: Stable row id: the table id and the row number
  table: Table id (see the methods page for the list)
  tableTitle: The table's title
  dimension: What the row measures
  value: The middle of the band (or the rounded value); read the display column or the note for the band
  unit: Unit of the value; "(band)" or "(tier)" means the figure is a range, not a point
  display: The figure as published: a band, a named tier or a rounded value
  kind: band, tier or rounded
  n_band: A rough size band for the row (30+ or 100+)
  note: The band or tier again, and what the figure counts
  version: Release version of the benchmarks
  lastChecked: The release date (YYYY-MM-DD)
  sourceLabels: The methods page that defines the measure
  sourceUrls: The methods page URL
  confidence: high, medium or low: computed from status, a second check, age against the refresh cadence and sampling error (rule: /data/#confidence)
  confidenceBasis: The reasons for the confidence level, in a short phrase
