Columns:
  id: Stable record id (never reused)
  jurisdiction: Two-letter state code, or US
  level: us, state or county
  area: US, the 2-digit state FIPS code or the 5-digit county FIPS code
  areaName: County and state, state name, or United States
  stateName: State name (United States on the national record)
  status: P: CDC's own file
  text: The record in one plain-English sentence
  value: Drug overdose deaths per 100,000 residents in the latest year (the same as overdose_rate_latest)
  unit: Unit of value
  firstYear: First calendar year in CDC's file for this place
  latestYear: Latest calendar year in CDC's file for this place
  dataThrough: CDC's as-of date for the file
  overdose_deaths_latest: Drug overdose deaths in the latest year, unintentional or of undetermined intent: a number, or 1-9 as CDC prints it
  overdose_rate_latest: Those deaths per 100,000 residents; CDC models the rate when a place has 1-9 deaths
  suicide_deaths_latest: Suicide deaths in the latest year, from any cause: a number, or 1-9 as CDC prints it
  suicide_rate_latest: Those deaths per 100,000 residents; CDC models the rate when a place has 1-9 deaths
  homicide_deaths_latest: Homicide deaths in the latest year, from any cause: a number, or 1-9 as CDC prints it
  homicide_rate_latest: Those deaths per 100,000 residents; CDC models the rate when a place has 1-9 deaths
  firearm_deaths_latest: Firearm injury deaths in the latest year, of every intent: a number, or 1-9 as CDC prints it
  firearm_rate_latest: Those deaths per 100,000 residents; CDC models the rate when a place has 1-9 deaths
  firearm_homicide_deaths_latest: Firearm homicides in the latest year: a number, or 1-9 as CDC prints it
  firearm_homicide_rate_latest: Those deaths per 100,000 residents; CDC models the rate when a place has 1-9 deaths
  firearm_suicide_deaths_latest: Firearm suicides in the latest year: a number, or 1-9 as CDC prints it
  firearm_suicide_rate_latest: Those deaths per 100,000 residents; CDC models the rate when a place has 1-9 deaths
  effectiveFrom: When the fact took effect (YYYY-MM-DD), if known
  effectiveTo: When it stopped applying; empty while current
  lastChecked: The day it was last confirmed (YYYY-MM-DD)
  sourceLabels: Sources, separated by " | "
  sourceUrls: Source URLs, in the same order
  confidence: high, medium or low: computed from status, a second check, age against the refresh cadence and sampling error (rule: /data/#confidence)
  confidenceBasis: The reasons for the confidence level, in a short phrase
