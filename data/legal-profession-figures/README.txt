Columns:
  id: Stable row id
  group: FIGURE-<id>
  groupType: lawyers, paralegals or access
  segment: The figure id
  displayValue: The figure as the source prints it
  figure: What the figure measures
  sourceName: The issuing source
  sourceUrl: The source the figure was re-read at
  quote: The series code or verbatim words that carry the figure at the source
  read: Date the source was read
  value: The number alone
  unit: The figure with its unit
  text: The row in one sentence
  version: Dataset version
  lastChecked: Date checked
  sourceLabels: Source label
  sourceUrls: Source URL
  confidence: high, medium or low: computed from status, a second check, age against the refresh cadence and sampling error (rule: /data/#confidence)
  confidenceBasis: The reasons for the confidence level, in a short phrase
