Not legal advice. These are counts of notices that employers filed with the Texas Division of Workers' Compensation. A non-subscribing employer can be sued for its negligence by an injured worker, but whether any claim exists depends on the facts; claims and deadlines are for your own counsel. The count of employers is a floor: not every non-subscriber files, and a filing covers a year.
Probative is a marketing firm, not a law firm; not legal advice.

Columns:
  id: Stable record id (never reused)
  jurisdiction: TX
  level: state, county, small-counties or county-not-recorded
  stateName: 
  status: P: the state agency's own filings
  text: The record in one plain-English sentence
  value: Filings (state), non-subscribing employers (county), employers in small counties, or locations with no county
  unit: Unit of value
  locations: Location rows of those employers in the county
  dataThrough: Last filing date in the data
  effectiveFrom: When the fact took effect (YYYY-MM-DD), if known
  effectiveTo: When it stopped applying; empty while current
  lastChecked: The day it was last confirmed (YYYY-MM-DD)
  sourceLabels: Sources, separated by " | "
  sourceUrls: Source URLs, in the same order
  confidence: high, medium or low: computed from status, a second check, age against the refresh cadence and sampling error (rule: /data/#confidence)
  confidenceBasis: The reasons for the confidence level, in a short phrase
  county: Five-digit county FIPS code (in tx-nonsubscribers-values.csv, as id, column and value rows)
  countyName: County name (in tx-nonsubscribers-values.csv, as id, column and value rows)
  employers: Employers with at least one Texas location in the county (an employer in two counties counts in both) (in tx-nonsubscribers-values.csv, as id, column and value rows)
  employers_2024: Employers whose notice was received in 2024 (October to December) (in tx-nonsubscribers-values.csv, as id, column and value rows)
  employers_2025: Employers whose notice was received in 2025 (in tx-nonsubscribers-values.csv, as id, column and value rows)
  employers_2026: Employers whose notice was received in 2026 (to September) (in tx-nonsubscribers-values.csv, as id, column and value rows)
  filings: State record: notices of no coverage (DWC Form-005) in the file (in tx-nonsubscribers-values.csv, as id, column and value rows)
  filings_texas: State record: filings with at least one Texas address (in tx-nonsubscribers-values.csv, as id, column and value rows)
  filings_no_texas_address: State record: filings with no Texas address (in tx-nonsubscribers-values.csv, as id, column and value rows)
  counties: Number of counties with at least one non-subscribing employer (state record) or in the small-counties record (in tx-nonsubscribers-values.csv, as id, column and value rows)
  filings_2024: State record: filings received in 2024 (in tx-nonsubscribers-values.csv, as id, column and value rows)
  filings_2025: State record: filings received in 2025 (in tx-nonsubscribers-values.csv, as id, column and value rows)
