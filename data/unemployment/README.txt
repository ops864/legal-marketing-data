Columns:
  id: Stable record id (never reused)
  jurisdiction: Two-letter state or territory code
  level: county or state
  stateName: 
  period: The period of the headline figure
  year: The latest complete annual-average year
  status: P primary source, S secondary source
  text: The record in one plain-English sentence
  value: Unemployment rate, percent, latest annual average
  unit: Unit of value
  unemployment_rate: Unemployment rate, percent, latest annual average (not seasonally adjusted)
  unemployed: People unemployed, annual average
  employed: People employed, annual average
  labor_force: Civilian labor force, annual average
  rate_change_1y: Change in the rate from the year before, percentage points
  latest_month: The latest month in the file (YYYY-MM)
  latest_month_rate: Unemployment rate in that month, percent
  latest_month_preliminary: true while BLS has not yet revised that month
  latest_month_unemployed: People unemployed in that month
  latest_month_labor_force: Labor force in that month
  effectiveFrom: When the fact took effect (YYYY-MM-DD), if known
  effectiveTo: When it stopped applying; empty while current
  lastChecked: The day it was last confirmed (YYYY-MM-DD)
  sourceLabels: Sources, separated by " | "
  sourceUrls: Source URLs, in the same order
  confidence: high, medium or low: computed from status, a second check, age against the refresh cadence and sampling error (rule: /data/#confidence)
  confidenceBasis: The reasons for the confidence level, in a short phrase
  county: 5-digit county FIPS code as BLS uses it (Connecticut by planning region); empty for states (in unemployment-values.csv, as id, column and value rows)
  countyName:  (in unemployment-values.csv, as id, column and value rows)
  rate_change_since_2015: Change in the rate since 2015, percentage points (in unemployment-values.csv, as id, column and value rows)
  note: Caveats (in unemployment-values.csv, as id, column and value rows)
