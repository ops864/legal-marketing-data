Columns:
  id: Stable record id (never reused)
  jurisdiction: Two-letter state or territory code, or US
  level: us or state (every state, DC, Puerto Rico, American Samoa, Guam, the Northern Mariana Islands and the U.S. Virgin Islands)
  area: US, or the 2-digit state FIPS code
  areaName: Jurisdiction name
  stateName: Jurisdiction name
  status: P: the Department's own state-level data file
  text: The record in one plain-English sentence
  value: Due process complaints filed in the latest published school year (the same as dpc_latest)
  unit: Unit of value
  firstYear: First school year in the file for this jurisdiction (for example 2012-13)
  latestYear: Latest school year published for this jurisdiction
  wsc_latest: Written, signed state complaints (item 1)
  wsc_reports_latest: Written complaints with a report issued (1.1)
  med_requests_latest: Mediation requests (2)
  med_held_latest: Mediations held (2.1)
  dpc_latest: Due process complaints (3)
  res_meetings_latest: Resolution meetings held on due process complaints (3.1)
  hearings_latest: Due process hearings fully adjudicated (3.2)
  dpc_withdrawn_latest: Due process complaints withdrawn or dismissed (3.4)
  effectiveFrom: First day of the latest school year (July 1)
  effectiveTo: Last day of the latest school year (June 30)
  lastChecked: Date the files were last re-read from the Department
  sourceLabels: Sources, separated by " | "
  sourceUrls: Source URLs, in the same order
  confidence: high, medium or low: computed from status, a second check, age against the refresh cadence and sampling error (rule: /data/#confidence)
  confidenceBasis: The reasons for the confidence level, in a short phrase
