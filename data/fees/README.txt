Columns:
  id: Stable record id (never reused)
  jurisdiction: Two-letter state code, DC, US (federal), ABA, or PLATFORM:<name>
  jurisdictionName: Jurisdiction name
  program: workers-comp, med-mal, contingency-general, ssdi-ssi, ftca, va, longshore or other
  status: P primary source, S secondary source
  capType: percent, dollar, lesser-of, sliding-scale, approval-required, reasonableness-only or unknown
  approval: Who approves the fee: agency, judge, none or unknown
  citation: The statute, rule or regulation cited
  text: The record in one plain-English sentence
  lastChecked: The day it was last confirmed (YYYY-MM-DD)
  sourceLabels: Sources, separated by " | "
  sourceUrls: Source URLs, in the same order
  confidence: high, medium or low: computed from status, a second check, age against the refresh cadence and sampling error (rule: /data/#confidence)
  confidenceBasis: The reasons for the confidence level, in a short phrase
  percent: The headline maximum percent, if the rule sets one (in fees-values.csv, as id, column and value rows)
  percentKind: ceiling (a hard cap), presumption or fee-award (a limit on an award only); empty when none (in fees-values.csv, as id, column and value rows)
  dollarCap: A dollar ceiling on the fee, if the rule sets one (in fees-values.csv, as id, column and value rows)
  base: What the percent applies to, in the rule’s words (in fees-values.csv, as id, column and value rows)
  effectiveFrom: When the fact took effect (YYYY-MM-DD), if known (in fees-values.csv, as id, column and value rows)
  effectiveTo: When it stopped applying; empty while current (in fees-values.csv, as id, column and value rows)
  detail: A short sourced detail on the record (in fees-values.csv, as id, column and value rows)
