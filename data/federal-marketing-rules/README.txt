Not legal advice. A plain-English summary of federal rules and statutes, kept for marketing planning. Each row quotes the official text it rests on; read that text and ask your own counsel before you rely on a row, and check your state bar's rules, which add their own.
Probative Growth is a marketing firm, not a law firm; not legal advice.

Human page: https://probativegrowth.com/data/federal-marketing-rules/

Columns:
  id: Stable record id (never reused)
  law: The rule or statute: 16 CFR 1.98, 16 CFR 255, 16 CFR 310, 16 CFR 316, 16 CFR 465, 47 CFR 1.80, 47 CFR 64.1200, 15 U.S.C. 7704, 15 U.S.C. 7706 or 47 U.S.C. 227
  lawKey: The lookup key of the rule or statute (the per-key file name): 16-CFR-465, 47-U-S-C-227 and so on
  lawName: The rule or statute in plain words
  cite: The section and paragraph the row rests on
  agency: 
  topic: penalties, reviews, endorsements, telemarketing, email or calls-and-texts
  kind: amount (a dollar figure) or duty (something a sender, caller or advertiser must or must not do)
  status: P primary source, S secondary source
  text: Our plain-English summary of the quoted text
  textEs: The same summary in Spanish
  quote: The official text the row rests on, word for word (the other quotes it rests on are in the JSON sources)
  currentSince: The day the section's current text took effect: for a CFR section, the newest version in the eCFR version history; for the US Code, the date of the latest law in the section's source credit. A CFR section unchanged since the eCFR version history begins shows that history's first date
  currentSinceBasis: ecfr-version-history or us-code-source-credit
  lastChecked: The day we read the section (YYYY-MM-DD)
  sourceUrl: The section's public page
  sourceLabels: Sources, separated by " | "
  sourceUrls: Source URLs, in the same order
  confidence: high, medium or low: computed from status, a second check, age against the refresh cadence and sampling error (rule: /data/#confidence)
  confidenceBasis: The reasons for the confidence level, in a short phrase
  value: The dollar figure, on amount rows (in federal-marketing-rules-values.csv, as id, column and value rows)
  unit: What the figure counts (dollars, dollars per violation, per message, per area code) (in federal-marketing-rules-values.csv, as id, column and value rows)
  valueText: The figure as the official text prints it; it sits inside the quote (in federal-marketing-rules-values.csv, as id, column and value rows)
  lastChangedBy: US Code rows: the latest public law in the section's source credit (in federal-marketing-rules-values.csv, as id, column and value rows)
  usCodeEdition: US Code rows: the edition read on govinfo (in federal-marketing-rules-values.csv, as id, column and value rows)
  pendingEffective: A published change to this section that takes effect later: its effective day (the JSON has its summary and source) (in federal-marketing-rules-values.csv, as id, column and value rows)
  pendingCitation: The Federal Register citation of that change (in federal-marketing-rules-values.csv, as id, column and value rows)
